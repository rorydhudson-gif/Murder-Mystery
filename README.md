# Death the Halls — GitHub Pages game (complete test build)

## Deploy
1. Extract this ZIP.
2. Upload the **contents** of `Death_the_Halls_GitHub_Pages` (index.html, style.css, app.js, and assets/) to the **root** of your GitHub repository.
3. In GitHub Settings > Pages, select Deploy from a branch, then main / (root).
4. Visit the published URL on your iPhone and test all three stages.

## Workflow
- First: acknowledge Chief Inspector Frost’s initial email, assess all seven people and attach evidence, then pass the preliminary case review.
- Second: read all eight supplementary evidence emails. Only after all eight have been opened does Frost’s second review email arrive. Open/acknowledge it, revisit only the five continuing enquiries (Rory, Nicole, Lara, Mark and Jonty). The first review and all its evidence stay saved; attach one or more NEW relevant exhibits to each reopened person and submit to unlock the final archive. Chloe and Ste stay closed and require no new selections.
- Third: read all four final evidence emails. Only after all four have been opened does Frost’s final accusation email arrive. Acknowledge, submit your accusation with motive, supporting evidence and written reasoning, then unlock the reconstruction.
- Wrong submissions have tailored feedback and unlimited resubmission.
- State is saved locally in the browser. Use "Review history" to reset for a fresh test.

## Important limitations
This is a static GitHub Pages game. Files and solution-checking code included in the published repository are technically accessible to anyone who inspects the public files or JavaScript. The interface hides future evidence until unlocks, but this is a narrative gate, **not secure access control**. For stricter secrecy, a server/backend would be required.

All files are included and referenced by relative paths. Browser PDF previews may vary by device; there is a separate open-attachment link for every file. Some earlier generated newspaper/WhatsApp images may need a final content review. The Evidence 020 photograph is the latest user-selected photo. Evidence 025 is the exact user-approved Toby email text shown in the inbox, not a fabricated PDF.

## Updated second review
The original first-review assessments remain stored and shown on each reopened person’s page. Stage two presents only Evidence 018–025 for ticking. Evidence already selected does not need to be selected again. One relevant new item is enough to justify an updated recommendation.
